# Jarvis AI Assistant

Jarvis AI Assistant is an independent Python cybersecurity portfolio project that combines AI assistant functionality with beginner-friendly security monitoring tools.

The project is being developed to improve my skills in Python, AI integration, GUI development, automation, network scanning, and ethical cybersecurity practices.

---

## Overview

Jarvis is a desktop AI assistant built with Python and Tkinter. It can respond to user commands, support voice interaction, provide AI-powered responses, summarise news, store notes, and include cybersecurity-focused features such as local network scanning, device monitoring, alerting, and safe demo modes.

This project is currently in active development and is being shared feature-by-feature as part of my cybersecurity portfolio.

## Safe and Ethical Use

This project is designed for educational and ethical cybersecurity learning only.

Any network scanning or device monitoring features should only be used on networks and devices that I own or have explicit permission to test. The project is not intended for unauthorised scanning, exploitation, or harmful activity.

The safe demo and simulation features are designed only for controlled demonstrations.
